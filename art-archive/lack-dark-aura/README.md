# Lack Dark-Aura

> A red Lucario, an old friend, and the character who taught me how to draw.

---

## Overview

**Lack Dark-Aura** is an alternative, red-colored Lucario and my oldest original
character (The first one). He was created around the **early 2010s**, long before I moved to the
My Little Pony fandom. The exact creation date is unknown — I did not keep records back.

He started as one of my very first **recolor** characters. Years later, after I actually
learned how to draw, I redesigned him into something far more original than a palette swap.

---

## Design Notes

Lack Dark-Aura is a Lucario, but he is not a simple color swap. The design differences are
intentional and consistent:

| Feature | Original Lucario | Lack Dark-Aura |
| --- | --- | --- |
| Fur (main) | Blue | **Red** |
| Torso / chest | Yellow | **Pure white** |
| Hair | None | **Yes** — a defining trait |
| Eyes | Standard shape | **Custom shape** |

### What makes him recognizable

1. **Red fur** where the original blue would be.
2. **Pure white** where the original yellow would be.
3. **Hair** — not part of the original species design.
4. **Eye shape** — deliberately different from the reference species.

If you are drawing him, those four points are the ones that matter most.

## The Main Image

The image in this folder is the reference piece. It shows Lack Dark-Aura sitting at a
computer — and that computer is the exact model I was using when I drew it.

The desk is not generic either. It is a drawn version of my real desk, including the same
objects that were sitting on it at the time. Nothing in that scene was invented; it is a
faithful copy of the room as it was.

That makes this drawing a timestamp. It is not only a picture of the character, but also a
record of where I was and what my setup looked like when I made him.
