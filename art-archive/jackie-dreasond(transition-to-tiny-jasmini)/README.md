# Legacy — Tiny Jasmini (Pre-Current Design)

This folder does not represent the current version of Tiny Jasmini.

## Overview

This folder contains an older, legacy version of my character, **Tiny Jasmini**.

Everything stored here predates her current design. These files are kept for historical
reference only, so the character's evolution can be traced over time. Nothing in this
directory should be treated as an accurate reference for how the character looks,
behaves, or is written today.

The character in these files is an **earlier iteration**. She is related to the current
Tiny Jasmini, but she is not her yet.
