# Jackie Dreansod — Original Character

## About This Folder

This folder contains drawings made by me, featuring my original character
**Jackie Dreansod**.

All artwork here is hand-made by me. The character, the designs, and the
illustrations belong to this personal collection.

## Who Is Jackie Dreansod?

Jackie Dreansod was my original character (OC), created in **November 4, 2014**.

He was my main persona and self-insert: the character I used to represent
myself in my art before I changed my internet identity to my current one Tiny Jasmini, as part of my transgender changes.
