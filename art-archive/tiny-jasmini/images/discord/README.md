# Discord Emoji Repository

A collection of custom emoji assets packaged for use on Discord.

## Overview

This folder is an **emoji repository**. Every image here is meant to be uploaded to a Discord
server and used as a custom emoji in messages and reactions.

The images are adapted versions of existing images taken from the `human-made/` and `ai/` folder. In other words, this directory holds the emoji-sized, Discord-ready
derivatives, while the source artwork stays in the original folders.

## What "adapted" means here

Typical changes applied to the original artwork:

- Cropping to a square aspect ratio.
- Resizing to fit Discord's emoji limits.
- Background removal or transparency cleanup.
- Format conversion and compression to keep file size low.
